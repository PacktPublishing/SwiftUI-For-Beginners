  <summary><h2>About the book</summary>
<a href="https://www.packtpub.com/en-us/product/swiftui-for-beginners-first-edition/9781807785574">
<img src="https://content.packt.com/B38840/cover_image_small.jpg" alt="SwiftUI for Beginners, First Edition" height="256px" align="right">
</a>

Most beginners want to build a real app, not work through isolated exercises. <i>SwiftUI for Beginners</i> gets you building from the start, showing you how to create a complete iOS app on iPad using Swift Playground, Swift 6, and SwiftUI.</br>
Starting with the Swift Playground environment and Swift fundamentals, you will design adaptive multiscreen interfaces, build navigation flows, and manage application data. As the app grows, you will add SwiftData for persistent storage, Core Location and MapKit for location-aware features, and Photo Library integration for rich media. You will also build reusable custom views and implement search to 
improve usability throughout.</br>
By the end of this book, you will have built, tested, and published a complete iOS app to the App Store using SwiftUI, SwiftData, MapKit, and TestFlight.</br>
</details>

<details open> 
  <summary><h2>Requirements for this book</summary>
To complete all the exercises in this book, you will need:
<ul>
  <li>An iPad running iPadOS 26 or later</li>
  <li>Swift Playground 4.7 or later</li>
</ul>
To check whether your iPad supports iPadOS 26, see this link: https://www.apple.com/my/os/ipados/. If your iPad is supported, you can update iPadOS using software update in the <b>Settings</b> app.</br></br>
To get the latest version of Swift Playground, you can download it from the App Store. Most of the exercises can be completed without an Apple Developer account and use the iPad to run your app. If you wish to test the app you are developing on other Apple devices, you will need a paid Apple Developer account.</br></br>
The following chapters require a paid Apple Developer account:
 <ul>
  <li><i>Chapter 13</i>, <i>Test Your App with TestFlight</i></li>
  <li><i>Chapter 14</i>, <i>Submit Your App to the App Store</i></li>
</ul>
Instructions on how to get a paid Apple Developer account are included in <i>Chapter 13</i>, <i>Test Your App with TestFlight</i>.
